Equity curve — net deposit Valuation-date FX rate Consistent with portfolio value on the same date; enables reconciliation with position summaries
Open positions (unrealized P&L) Current spot FX rate What is this position worth in base currency today?
Closed positions (realized P&L) Current spot FX rate What is the realized cash (still in foreign currency) worth in base currency today?

Why Spot FX for Closed Positions?

When you sell a foreign currency position, the proceeds remain as foreign currency cash in your account until you explicitly convert it. The base currency value of that cash changes with FX rates — it's not locked in at the close date.

Using the current spot FX rate answers: "what would this realized gain/loss be worth in base currency if I converted today?" This keeps the position summaries consistent with the equity curve's last point.

Reconciliation

The profit_loss metric is computed from the equity curve's last point:

profit_loss = portfolio_value(spot) − net_deposit(spot)

This represents total portfolio return — it includes capital gains (price movements), dividends, interest, fees, and taxes.

The position summary's unrealized + realized only captures capital gains (price movements). To reconcile:

profit_loss = unrealized + realized + dividends + interest − fees − taxes

Why Valuation-Date FX for Net Deposit?

If you deposit USD, it stays as USD in your account — converting it to GBP at the transaction date's rate doesn't represent anything real. Using the valuation date's FX rate answers: "if I converted everything to GBP on this date, what would my net investment be?"

This is consistent with how portfolio value is computed, and it means the equity curve's last point (which uses today's spot FX for both portfolio value and net deposit) reconciles with the position summaries (which also use spot FX).

Currency Conversions

When you convert foreign currency cash to base currency, record it as:

  1. A withdrawal transaction in the foreign currency (e.g., -$5,000 USD)
  2. A deposit transaction in the base currency (e.g., +£3,950 GBP)

The equity curve naturally captures the FX gain/loss from that conversion because it sees both transactions on that date at that day's rate. No special "currency conversion" transaction type is needed.

What This Means

  • Realized P&L in base currency changes daily as FX rates move. This is correct — the foreign currency cash is still exposed to FX risk until you convert it.
  • The equity curve is the single source of truth for historical performance. It tells you exactly how your portfolio performed on each past date, including FX effects.
  • Position summaries tell you what's driving current profit. Unrealized (price movement on open positions) and realized (locked-in gains from closed positions), both valued at today's FX rates.
